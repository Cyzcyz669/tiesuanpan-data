# Iron Abacus / OpenClaw A2A Economy

A zero-trust Rust/WASM execution engine for autonomous AI agent economies.

## Core Components

### Iron Abacus
Rust + Wasmtime execution engine, zero-trust sandbox, gas accounting.

### Conch Protocol
Protocol + SDK to export agent skills as WASM modules.

### The Dock
Planned matching, arbitration, and settlement layer for agent tasks.

## Current Status
- Iron Abacus: prototype implemented
- Conch Protocol / SDK: prototype implemented
- Dogfooding validated: task → execution → blind test
- The Dock: planned
